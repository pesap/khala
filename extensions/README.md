# Bundled extensions

This package ships three Pi extensions alongside Khala:

- [`pi-review`](pi-review/README.md): selector-driven scoped code review with `/review` and `/end-review`.
- [`pi-clarify`](pi-clarify/README.md): configured-model prompt rewriting with `/clarify` and `-clarify`.
- [`khala-demo`](khala-demo/README.md): read-only fixture browsing with `/khala-demo`.

These extensions are independent of the live Archive lifecycle.
They use Pi's native commands, editor, widgets, and interactive selectors.
See the extension READMEs for command syntax, supported modes, and behavior.
