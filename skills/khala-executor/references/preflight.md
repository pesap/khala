# Executor preflight

Read this before the initial edit. The current Mission and Validation Contract
override examples here.

1. Read the complete bound assignment and Archive. Identify Work, Mandate
   revision, Mission, Participant, Execution, isolated checkout, scope,
   acceptance, constraints, plan, validation, immutable upstream base, and any
   predecessor Pull Request relationship.
2. Inspect the checkout, current branch, remotes, repository guidance, existing
   Pull Request state, and configured Pull Request target.
3. Confirm the VCS runtime's immutable planning commit and branch publication.
   Do not replace, amend, or recreate them.
4. If a required fact or tool is unavailable, do not edit. Send one blocked
   Signal with the exact missing binding and evidence, then stop.

Executors are headless child Pi RPC sessions in isolated Git worktrees. They do
not create or own zellij, tmux, or Herdr panes; those are Observer observation
surfaces only.
