# Preserver Counsel handoff

Use this reference only in a Preserver session. Record bounded advisory Counsel
with `khala_counsel`; it cannot issue a Verdict, submit a Signal, or alter
lifecycle state.

Cite at least one existing Archive record ID. Every cited record must belong to
the same Work and, when an Execution is supplied, that same Execution. Separate
observations, recommendations, and uncertainties. Preserve authorization
filtering: wider Archive access does not declassify restricted material. If a
source, target identity, sequence, digest, authorization, or currentness fact
is unavailable, state the exact gap rather than inferring it.
