# Khala artwork

The README is designed for two original, AI-generated images. Keep the artwork
original and avoid logos, screenshots, or copied game assets. The visual brief is
**Protoss-inspired science-fantasy**, not a reproduction of any copyrighted
character or franchise artwork.

## `assets/khala-hero.png`

- Aspect ratio: 3:1 or wider
- Recommended size: 1800 × 600 px
- Use: README hero image
- Composition: wide negative space around the central subject so the image crops
  cleanly on GitHub mobile

### Prompt

> Wide cinematic science-fantasy concept art for an open-source coding-agent
> coordination system called Khala. A serene Protoss-inspired council of five
> luminous alien mentors stands around a floating geometric archive, connected
> by thin cyan and violet energy threads. The central figure represents a
> Conclave, with four distinct silhouettes representing User, Observer, Executor,
> and Preserver. Ancient golden armor, elegant angular forms, glowing teal
> circuitry, deep indigo space, subtle nebula dust, architectural symmetry,
> restrained composition, high contrast, premium editorial illustration, no text,
> no logos, no interface, no watermark, original character design.

## `assets/khala-lifecycle.png`

- Aspect ratio: 16:9
- Recommended size: 1600 × 900 px
- Use: optional image for the documentation or project announcements
- Composition: clear left-to-right visual flow

### Prompt

> Editorial concept illustration for an open-source software architecture called
> Khala. A luminous golden archive at the center sends five stages through a
> clean circular flow: a human request, a council reviewing it, a quiet observer
> gathering context, an armored executor working inside a translucent isolated
> cube, and an evidence signal returning to the council. Protoss-inspired alien
> silhouettes, cyan, electric blue, violet, and warm gold palette, geometric
> energy bridges, dark indigo background, clear visual hierarchy, sophisticated
> technical illustration, no text, no logos, no watermark, original design.

## Negative prompt

Use this with either prompt when supported:

> blurry, muddy lighting, photorealistic human, recognizable existing character,
> franchise logo, game UI, readable text, labels, letters, watermark, signature,
> extra limbs, malformed hands, duplicated figures, random symbols, cluttered
> background, oversaturated red, low contrast

## Adding the images

Save the generated files at exactly:

```text
assets/khala-hero.png
assets/khala-lifecycle.png
```

The README already references the hero path. Keep the generated files optimized
for the web; a compressed PNG or WebP is preferred. If WebP is used, update the
README extension and keep the alt text unchanged.
